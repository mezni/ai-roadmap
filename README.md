# AI Roadmap

A structured roadmap for tracking AI learning, experiments, and projects.

## Goals
- Document a clear learning path for AI concepts and tools
- Track practical progress with hands-on projects
- Keep resources and notes organized in one place

## Quick Start
1. Clone this repository
2. Review [ROADMAP.md](ROADMAP.md) to see planned milestones
3. Update [PROGRESS.md](PROGRESS.md) as you complete tasks

## Structure
- `ROADMAP.md` – Planned learning path and milestones
- `PROGRESS.md` – Ongoing log of completed work
- `CONTRIBUTING.md` – Guidelines for contributing
- `LICENSE` – Project license
