# Roadmap

This document outlines the planned learning path and key milestones for this AI roadmap.

## Phase 1: Foundations (Weeks 1-2)
- [ ] Core AI/ML concepts (supervised, unsupervised, reinforcement learning)
- [ ] Math fundamentals (linear algebra, statistics, probability)
- [ ] Python for AI and data manipulation

## Phase 2: Practical ML (Weeks 3-5)
- [ ] Training and evaluation of classic ML models
- [ ] Feature engineering and data preprocessing
- [ ] Hands-on projects with scikit-learn

## Phase 3: Deep Learning & LLMs (Weeks 6-8)
- [ ] Neural networks fundamentals with PyTorch
- [ ] Introduction to transformers and LLMs
- [ ] Prompting, RAG, and fine-tuning basics

## Phase 4: Applied AI Projects (Weeks 9-12)
- [ ] Build 1-2 end-to-end AI projects
- [ ] Explore deployment (APIs, containers, hosting)
- [ ] Document learnings and share results

## Resources
- [fast.ai](https://www.fast.ai/) – Practical deep learning course
- [3Blue1Brown](https://www.3blue1brown.com/topics/neural-networks) – Visual explanations
- [Hugging Face Course](https://huggingface.co/learn) – LLMs and transformers

## Notes
Adjust milestones based on your goals, time, and prior experience.
