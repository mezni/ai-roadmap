# Contributing to AI Roadmap

Thank you for your interest in contributing to this project! We welcome improvements, corrections, and new ideas.

## How to Contribute
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes with clear, well-documented commits
4. Update relevant docs (`README.md`, `ROADMAP.md`, `PROGRESS.md`) if needed
5. Push to your branch and open a Pull Request

## Guidelines
- Keep content clear, concise, and actionable
- Follow existing markdown formatting and structure
- Cite sources when adding learning resources
- If adding code examples, ensure they are well formatted and easy to read

## Issues
If you find typos, broken links, or have suggestions, please [open an issue](https://github.com/yourusername/ai-roadmap/issues).

## Code of Conduct
Be respectful, inclusive, and collaborative in all interactions.
